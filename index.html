Cone requirement

Cone rule: colour quantity below 2000 pcs uses 2000-meter cones; 2000 pcs or above uses 4000-meter cones. Cones = total thread ÷ cone length, rounded up when ordering. Metres = inches × 0.0254. Header order qty + extra % (default 3%) applies to body/contrast cone rows (typed or inherited); a new custom colour row with no typed qty inherits the header qty + header %; once you type its own qty, that qty is used exactly and an empty % means none (never double-added). Each cone row also has its own Extra % beside Qty: a typed % replaces the fallback for that row. Cone Qty shows the quantity with extra % already added (5000 + 3% shows 5150).
